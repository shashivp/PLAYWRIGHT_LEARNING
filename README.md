# Playwright Learning

This repository contains Playwright learning examples and practice code.

## Structure

- `Verify_setup.js` - Browser setup and verification sample.
- `_Identifiers_literals_operators.js` - JavaScript fundamentals practice.
- `01_Basics.js` - Playwright base examples.
- `chapter_01_var_let_const/var_let_learning.js` - Variable declaration practice using `var`, `let`, and `const`.

## Notes

- The repository is intended for learning Playwright and JavaScript basics.
- Add more chapters and examples as you continue learning.

## Usage

1. Install dependencies if needed.
2. Run sample scripts with Node.js.

```powershell
node Verify_setup.js
```
